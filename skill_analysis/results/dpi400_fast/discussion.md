# 考察 — 400 DPI / FAST（手書き。条件間の比較は `../_compare/discussion.md`）

- **追従精度**: RMS A 8.6 / B 9.7 / C 10.0 mm、on-target 31 / 29 / 25 %。向きは SLOW と同じ（高練度ほど良い）だが、
  差は縮まり、p < 0.1 は on-target・線形追従率・ゲインだけ。課題が難しく、全員の on-target が 24〜33 % に落ちている。
- **軌道修正**: SLOW で見えた「小さいうちに直す」差（修正開始時の誤差・外れる頻度・2–10 Hz の揺れ）は消える。
  外れる頻度は群平均で 1.5〜1.6 回/s で、ずっと外れては戻る状態になっており、修正の質の差が出る余地がない。
- **関節**: 全員が肘主導（群平均のシェア 0.57〜0.66）。x の手首シェアは高練度ほど大きい向き（A 除外 0.19 / B 0.28 / C 0.13）で、ほかの条件と同じ。
  肩のシェアが速い周波数で減る度合いが高練度で大きい（ρ −0.69、D = 0.5 で不安定）。
  Syou 除外で肩–肘の相関が高練度ほど低い（ρ −0.76）のは 400 SLOW と同じ（400 DPI に共通）。
- **Syou**: 体幹シェア z = +19.5、サブムーブメント超過 z = +5.3。成績は A 群の範囲（RMS 8.9 mm）。
- **B 群**: Kakeru（8.5 mm、33 %）は A 並み、Xin（10.8 mm、24 %）は C 並み。
