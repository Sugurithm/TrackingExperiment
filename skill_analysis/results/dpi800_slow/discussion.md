# 考察 — 800 DPI / SLOW（手書き。条件間の比較は `../_compare/discussion.md`）

- **追従精度・修正**: 400 SLOW とほぼ同じ構図。RMS A 2.7（除外 2.5）/ B 3.0 / C 3.6 mm、on-target 95 / 92 / 87 %。
  修正開始時の誤差（3.6 / 3.9 / 4.5 mm）、外れる頻度（0.26 / 0.37 / 0.70 回/s）、2–10 Hz の揺れ（10.9 / 14.2 / 17.7 mm/s）で
  はっきり練度差があり、q ≈ 0.10。**「小さいうちに直す」は SLOW に共通の特徴**（DPI によらない）。
- **関節: 4 条件の中で練度差が最もはっきり出る条件**。
  - 高練度ほど肘のシェアが小さく（A 0.48 / B 0.57 / C 0.60、ρ −0.82）、手首【参考】が大きい（0.22 / 0.27 / 0.13、ρ +0.69 / 除外 +0.79）。
  - その結果 N_eff（関与関節数）が高練度ほど大きい（2.82 / 2.39 / 2.30、ρ +0.82）。400 DPI では見られない。
  - 400 → 800 で x の手首シェアが A・B では倍増、C ではわずかしか増えない。感度が上がって手の移動が減ったときに、
    **高・中練度は細かい動きを手首に移し、低練度は肘のまま**動かしている、という読み。
  - 肩と肘が逆向きの割合は高練度ほど**小さい**（ρ −0.76）。400 DPI と逆向きなので、練度の安定した特徴とは言えない。
- **Syou**: 体幹シェア z = +34.7、LDLJ z = −5.9、サブムーブメント超過 z = +3.0。成績は A〜B の範囲（RMS 3.2 mm）。
