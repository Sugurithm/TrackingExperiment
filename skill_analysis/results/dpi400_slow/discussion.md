# 考察 — 400 DPI / SLOW（手書き。`report.md` の数値を読んだもの）

> `report.md` は `run_skill.py` を回すたびに作り直されるが、このファイルは手で書いたもので上書きされない。
> 数値は 2026-10-23 実行時の `data/group_tests.csv`・`data/persons.csv` による。
> 人数は A 3 / B 2 / C 3 人。p は探索的な目安で、「差があると言える」水準ではない。

## 1. 追従特性：練度の順にはっきり並ぶ（Syou の有無に左右されない）

| 指標 | A 高 | A（Syou 除外） | B 中 | C 低 | ρ 全員 / 除外 | g(A−C) |
|---|---|---|---|---|---|---|
| RMS 誤差 [mm] | 2.75 | 2.62 | 3.13 | 3.63 | −0.82 / −0.87 | −3.3 |
| on-target [%] | 95.7 | 96.6 | 91.7 | 85.9 | +0.76 / +0.77 | +3.3 |
| ターゲットから外れる頻度 [1/s] | 0.23 | 0.18 | 0.37 | 0.60 | −0.82 / −0.85 | −1.9 |
| 位相遅れの平均 [ms] | 44 | 41 | 53 | 62 | −0.76 / −0.77 | −1.7 |
| 2–10 Hz の揺れ [mm/s] | 8.6 | 8.4 | 12.5 | 13.3 | −0.82 / −0.76 | −2.1 |

- 正確さ（RMS・on-target・VAF）、遅れ、課題外の速い揺れが A > B > C の順に並び、Syou を除いても ρ はほとんど変わらない。
  追従精度の族で BH 補正後も q ≈ 0.08、効果量 g は 1.5〜3.6 と大きい。**この条件で練度差が最もはっきり出るのは「追従の成績」そのもの**。
- 遅れは周波数ごとに見ると、x 軸のどの周波数でも A < B < C（[tracking_by_freq.png](figures/tracking_by_freq.png)）。
  位相の傾きから出す「実効遅れ」では差が出ないので、差は周波数によらない一定の位相のずれ（＝先読みの程度）として出ている。
- B 群は 2 人の中が割れている: **Kakeru は A 並み**（RMS 2.73 mm、on-target 95.8 %）、**Xin は C 並み**（3.53 mm、87.5 %）。
  「中練度」を 1 つの群として読むのは慎重に。

## 2. 滑らかさ：躍度では差がなく、「課題に無い速い成分」で差が出る

- 躍度比・LDLJ（カーソルとターゲットの差）には練度との関係が見えない（ρ ≈ −0.2〜+0.1）。
- 一方、カーソル速度のうち課題外の帯域（≥ 0.98 Hz）の割合と 2–10 Hz の揺れは高練度ほど小さい（ρ −0.82）。
  躍度は 1 本の大きな修正にも小さな揺れにも反応するが、揺れの帯域で見ると低練度ほど**小刻みな修正・ふらつきが多い**。
- Syou は精度は A 群の範囲なのに、LDLJ（z = −4.7）とサブムーブメントの超過（z = +3.9）で 1 人だけ外れている。
  **精度は高いが、ぎくしゃくした（区切りの多い）動きで合わせている**。

## 3. 軌道修正：「速く直す」ではなく「小さいうちに直す」

- 修正を始めた時点の誤差（|e| の山の高さ）は A 3.6（除外 3.4）/ B 4.0 / C 4.5 mm（ρ −0.76）。ターゲットから外れる頻度も A が最少。
- 修正にかかる時間（山から谷まで）は約 0.2 s で群差は小さい（A 0.21 / B 0.19 / C 0.20 s。高練度がむしろわずかに長い）。修正の頻度は高練度ほど少ない傾向（ρ −0.63、有意でない）。
- 解釈: 高練度者は**ずれが小さいうちに検出して修正を始める**ため、外れる回数・修正の振幅が小さい。修正そのものの速さは変わらない。

## 4. 関節の寄与：分担の「型」はどの練度でも共通

- 全員が**肘関節（前腕の回転）主導**（シェア 58〜73 %。Syou のみ 47 %）。N_eff・遠位シェアに練度との関係は無い（Syou 除外でも |ρ| ≤ 0.3）。
- **軸ごとの分業**が全員に共通して見られる（[share_by_freq.png](figures/share_by_freq.png)）:
  x（左右）は肘関節が約 8 割 + 手首、y（前後）は肩関節（上腕の回転）が主役。これは練度ではなく課題（机上の 2 次元運動）の構造で決まっている。
- 弱い傾向（D < 1 で試行間のばらつきと同程度なので確定的でない）:
  - x 方向で高練度ほど**手首を使う割合がやや大きい**（手首【参考】ρ +0.69、肘 ρ −0.69）。
  - 速い入力周波数ほど手首の割合が増える度合いが高練度で大きい（ρ +0.82 / 除外 +0.94）が、変化量そのものは ±0.02 と小さい。

## 5. 時間軸の役割分担：高練度は肩と肘を「独立に・補い合って」動かす傾向（Syou 除外時）

- Syou を除くと、肩関節と肘関節の速度の相関が高練度ほど低く（ρ −0.94、p = 0.01、q = 0.07）、
  逆向きに動いている運動量の割合が高い（ρ +0.76）。A（除外）r = −0.05、C r = +0.19（Yuuki +0.34）。
  → 低練度は肩と肘が一緒に動く（まとめて腕を振る）、高練度は**肩と肘が別々に、互いの動きを補正し合うように**動く、という読みと整合する。
- 肘 → 手首のラグは高練度ほど負（手首が肘より先に動く。A −119 ms、C +7 ms、ρ −0.69）。手首が先行して細かく合わせ、肘が後から大きく運ぶ分業の可能性。
  ただし D = 0.6 で試行ごとのばらつきが大きく、手首は MoCap 未照合の【参考】なので仮説の段階。
- 相殺比 C は全群 1.07〜1.13 で、成分どうしの打ち消し合いは小さい。

## 6. Syou：成績ではなく「動かし方」の外れ値

- 成績（RMS 3.0 mm、on-target 93.9 %）は A 群の範囲内（ロバスト z −1.4〜+1.2）で、追従特性の結論は Syou を含めても除いても同じ。
- 一方、協調は他の 7 人と質的に違う:
  - **体幹（肩の並進）のシェア 35 %**（他は 1〜11 %、z = +73）。特に **y（前後）方向は 79 % を肩の並進で作り**、肩関節の回転は 16 %（他 35〜85 %）。
    高い周波数ほど肩の並進の割合が増える（周波数変化 z = −24）。
  - 肘角の範囲が狭く、手首角の範囲が広い（z −2.2 / +5.8）。
  - → 前後方向の動きを、上腕を回すのではなく**肩ごと（体幹の傾き・肩甲帯の前後）動かして**作っている。
- 既存の解析（`analysis_out/20261022/between/summary.md`）でも Syou の体幹シェアは全条件平均で 23 %（他は 1〜6 %）で、
  **この条件だけの偶然ではなく一貫したスタイル**。
- 扱いの提案:
  - 追従特性: Syou を含めてよい（結論が変わらない）。
  - 協調: **Syou を含める版と除く版を併記**する。Syou を含めると、体幹シェア・肩–肘の相関などの練度傾向が薄まる（Syou 除外 → 全員で ρ −0.70 → −0.25、−0.94 → −0.57）。
  - 肩の点の動きが姿勢推定の誤差でないことを確認動画で目視しておくとよい:
    `recordings/aim_Syou400_20261022_135724/trial_01_slow_s1/joints/joints_check_20fps.mp4`（slow s2・s3 も同じ場所）。

## 7. この条件でのまとめと、他条件で確かめること

- 400 DPI / SLOW では、**練度差は「どの関節を使うか」より「どれだけ正確に・早めに・揺れずに合わせるか」に出る**。
  関節の分担の型（肘主導、x = 肘・y = 肩）は練度によらず共通で、差は肩–肘の独立性や手首の使い方といった細部に、弱い傾向として現れる。
- 他条件で確認したい点（`compare_conditions.py` で条件 × 指標の表になる）:
  1. 追従精度の練度差が FAST でも保たれるか（遅い課題では天井に近いので、FAST の方が差が開く可能性）。
  2. 肩–肘の相関・手首の先行（D < 1 の弱い傾向）が別条件でも同じ向きに出るか。どの条件でも出れば偶然ではない。
  3. Syou の「肩ごと動かす」スタイルが DPI や速さで変わるか。
- 限界: 1 群 2〜3 人。p は全並べ替えの正確な値だが、多数の指標を見ているので、q と効果量・D を併せて読むこと。
