# 考察 — 800 DPI / FAST（手書き。条件間の比較は `../_compare/discussion.md`）

- **追従精度**: RMS A 7.6 / B 8.3 / C 8.9 mm、on-target 37 / 36 / 30 %。向きは他の条件と同じで、線形追従率（ρ +0.82）と
  ターゲットで説明できない動き（ρ −0.88）で練度差がはっきりしている。400 FAST より全員の成績が良い。
- **軌道修正**: 400 FAST と同じく、修正の質（開始時の誤差・外れる頻度）の差は消える（外れる頻度は群平均で 1.9〜2.0 回/s）。
- **関節**: 800 SLOW と同じく、高練度ほど手首【参考】を使い（x の手首シェア A 除外 0.43 / B 0.49 / C 0.22）、N_eff が大きい（ρ +0.69）。
  Syou を除くと、速い入力周波数ほど手首の割合が増える度合い（ρ +0.87）と、手首が手先より先に動く度合い（ρ +0.79）が高練度ほど大きい。
  → 速い成分を手首が先回りして担う、という分業が高練度で強い可能性（手首は【参考】なので計測の確認が前提）。
- **Syou**: 体幹シェア z = +17.8、N_eff z = +5.5、遠位シェア z = −4.3。この条件では滑らかさの指標は他の人と同程度。成績は A 群の範囲（RMS 8.1 mm）。
- **B 群**: Kakeru は on-target 43 % で全員中 1 位。Xin（28 %）は C 並み。
