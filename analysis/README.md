# 解析プログラム説明

### xcorr_trial.py
 - 目的: 試行ごと/関節ごとの変位を黙示確認するための波形描画
 - 処理:
    - 全関節の3軸変位(カメラ軸方面のX,Y,Z)の時系列データプロット
    - 全関節の変位ノルムの時系列データプロット
    - 隣接関節間の相対変位ノルムの時系列データプロット

### link_share.py
 - 目的: 手先全体の変位に対して，身体の各リンクがどれだけ貢献しているか
 - 処理: 手先変位ベクトルに対する各リンク相対変位ベクトルの正射影寄与率を算出
 - 出力: 協力者別・ターゲット速度別の各リンク寄与率及び変動(標準偏差)

### joint_lag_norm.py
 - 目的: 協調運動時において，関節Aから関節Bへの運動に生じる時間遅延を算出
 - 処理: 
  - 隣接関節ペアの変位ノルム時系列同士で正規化相互相関を計算
  - ピーク相関位置に対し，サブフレーム補完を適用し，ミリ秒単位遅れ時間を推定
 - 評価
  - 被験者内，被験者間の級内相関係数による再現性・個人差の評価

### joint_use_by_cursor_direction
 - 目的: 画面上のカーソルの運動方向ごとの関節寄与率及び，関節時間遅れ
 - 処理:
  - カーソルの速度ベクトルからフレームごとに移動方向を8方向に分割
  - 方向別寄与率: 各方向フレームにおけるリンク相対速度の手先速度への射影比率及び相対速度パワー比率を算出 <- パワー比率の意味と計算方法がわからない．
  - 方向別遅れ: 方向のフレームのみを基準点として相互相関により，関節速度ノルムの遅延を推定 <- 計算方法がわからない．

### joint_use_by_target_direction.py
 - 目的: 画面上のターゲットの運動方向ごとの関節寄与率及び，関節時間遅れ
 - 注意?:
  - 反応遅延等による手先と標的のズレを含んだ状態で，移動方向に対して身体各部がどのように動員されたかを分析
