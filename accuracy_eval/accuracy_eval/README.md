# accuracy_eval — RealSense + MediaPipe の精度評価

MoCap を真値として，RealSense + MediaPipe の 3 次元関節座標を 7 つの観点で評価する。
各プログラムは単独でも動き，`run_all.py` で全部まとめて実行できる。

## 使い方

```
python run_all.py recordings/trial_20261019_015509      # 全部 → <trial>/eval/summary.md と図
python a3_bias_stability.py recordings/trial_...        # 1 つだけ
python run_all.py --rs a.npz --mc b.npz --sync sync_result.json --tmc T_MC.json --out out/   # 個別指定
```

入力は試行フォルダから自動で探す: `joints/rs_joints.npz`，`joints/mc_joints.npz`，
`sync_check/sync_result.json`，`T_MC.json`（試行フォルダになければ sync_result の `calib` から `../calib_*/T_MC.json`）。
必要なもの: numpy，scipy，matplotlib。

## 共通の処理（common.py）

- **時刻**: Take 時刻 = RS 時刻 + c。c は sync の各区間の中央で直線補間する（区間の間の時計のずれの変化も補正）
- **座標**: MoCap を T_CM でカメラ座標に移し，誤差を **奥行き（視線方向，+ = RS が奥）／画像の横／画像の縦** に分ける
- **解析範囲**: 同期ボードの区間 ±1 s を除いた間
- **区間の自動検出**（MoCap の手首・肘から）: 静止 = 1 秒の振れ幅が 4 mm 未満，動作ブロック = 30 mm を超える部分（3 s 未満の切れ目はつなぐ），テンポは主な動きの方向の FFT から
- **前処理**: RS は Hampel（9 フレーム，3·MAD）+ 5 Hz ゼロ位相低域通過，MoCap は 5 Hz（両方に同じフィルタ）
- **大外れ**: status が OK でも真値から 100 mm 以上離れたフレームは誤検出として除外し，a6 で数える。
  そのうち反対側の腕の推定値（`P_C_left`）なら真値と合うものは **左右の取り違え**として別に数える（a7）
- **フェーズ（phases.py）**: `<trial>/meta.json` に合図音の `cue` があればそれを使う（`--meta` で指定も可）。
  なければ合図音の予定表（experiment/config.py の `CUE_*` と同じ値。config を変えたら phases.py の値も合わせる）を作り，
  記録開始から ±3 s ずらして MoCap の手首の動きと最もよく合う位置に置く（ずれには合図への反応の遅れも含む）。
  予定表が記録と合わなければ自動検出（board / still / bpmNN）に切り替える

## 解析の一覧

| # | プログラム | 方法（何をするか） | わかること | 主な指標 |
|---|---|---|---|---|
| a0 | `a0_reference.py` | 較正の残差，同期の残差，MoCap の静止時のゆらぎ・骨長のばらつきを集める | 真値側の誤差。**これより小さい RS の誤差は区別できない**（評価の下限） | 較正 RMS／LOO，同期の横方向誤差，drift，MoCap の SD |
| a1 | `a1_jitter.py` | 静止区間で RS − MoCap の SD を成分別に計算（体の微小な動きは MoCap で差し引く）。画像上の 2D の揺れ [px] も | **RS 単体の精密さ（再現性）**。真値がなくても測れる。揺れの原因が深度か MediaPipe の 2D か | σ（3D・奥行き・横・縦），フレーム間ノイズ，5 Hz 後の σ，最小検出変位 ≈ 2.8σ |
| a2 | `a2_accuracy.py` | RS − MoCap を関節 × 区間で集計 | **正確度**。絶対位置としてそのまま使ったときのずれ。偏りとばらつきのどちらが主か | 偏り（成分別），SD，RMSE，95%，一致限界（Bland–Altman） |
| a3 | `a3_bias_stability.py` | 1 秒ごとの偏りの時間変化。静止で測った偏りを動作に当てたときの RMSE。偏りの位置・速さへの依存を回帰 | **表面と関節中心のずれが一定か**。一定なら動き方の解析に使える。補正の方法（静止で 1 回測る，など）が有効か | 偏りの時間変動 SD，一定の偏りの割合，補正方法ごとの RMSE，位置・速さによる偏りの変化 |
| a4 | `a4_motion.py` | テンポごとに，偏りを除いた軌跡の形・遅れ・振幅・速さを比較 | **動きの再現性**。速くなると何が崩れるか。遅れは関節間のタイミング（協調）の誤差に直結 | 形の誤差（mm，範囲比 %），遅れ [ms]，振幅比，速さの r，最大の速さの比 |
| a5 | `a5_angles_segments.py` | 骨長の一定性，肘の角度，上腕・前腕の向きを比較 | **3D 座標から計算する量**（角度・向き）にどこまで使えるか | 骨長の SD・CV，肘の角度の偏り・SD・r・一致限界，セグメントの向きの誤差 |
| a7 | `a7_conditions.py` | 区間（meta.json の cue: board / still / bpmNN …）ごとに使えないフレームを原因別（欠損／左右の取り違え／その他の誤検出）に分ける。動作中は瞬間の速さ・ストロークの位置・ブロック開始からの時間で層別し，動きの方向の誤差と速さの関係から実効的な遅れを出す。フレームごとの条件と誤差を `a7_frames.csv` に書く | **誤差が試行のどの条件で大きくなるか**。速さで増える成分（遅れ・ブレ）と，速さと無関係な成分（誤検出・取り違え・一定の偏り）の切り分け | 区間別の取り違え率・誤検出率・除外後 RMSE，速さ別 RMS，実効的な遅れ [ms]，止まっているとき／1 m/s のときの誤差 |
| a8 | `a8_phases.py` | 試行を合図音のフェーズ（still / count#k / bpmNN / rest#k / board …）に分け，フェーズごとに a1〜a5 の指標を出す。静止フェーズは MoCap で実際に止まっているフレームだけを使う。動作フェーズは 1 拍ごとのストローク（片道）に分けて振幅比・折り返しの時刻のずれ・最大の速さの比を出し，動き始め・止まりの時刻のずれ（静止位置から 10 mm 離れた時刻）も出す。被験者が指示どおり動いたか（実テンポ，振幅のばらつき，ストップ後の動きすぎ）も記録 | **試行のどの場面で，どの種類の誤差が出るか**。静止で測った補正値が試行を通じて使えるか。関節の協調（タイミング）を解析するときの時刻の誤差 | フェーズ別の σ・偏り・SD・still 補正後 RMSE・遅れ・振幅比・速さの r・肘の角度，ストロークごとの振幅比・折り返しのずれ [ms]，動き始め・止まりのずれ [ms]，静止フェーズ間の偏りの SD |
| a6 | `a6_availability.py` | 関節ごとの有効率，status の内訳，大外れ・外れ値，最長の欠損，フレームの取りこぼし | **そもそも測れているか**，誤検出の頻度 | 有効率，大外れ率，外れ値率，最長欠損 [s]，fps |

`run_all.py` は各解析の表と，それらから拾った **要点の表**（関節ごとに ジッタ／絶対 RMSE／偏り／偏りの変動／補正後 RMSE／形の誤差／遅れ／速さの r／使える率）を `summary.md` に書く。

## 読むときの注意

- 遅れは手首（hand）の動きで合わせたのではなく，**ボードで求めた時計のずれ**で合わせた後の値なので，MediaPipe 自身の遅れがそのまま出る。遅いテンポでは遅れの推定が不安定（速いブロックの値を信頼する）
- 動きの SD が 20 mm 未満の関節（肩）は遅れ・振幅比・速さの相関を出さない（ノイズで決まるため）
- MoCap の上腕長は骨格モデルで固定（SD ≈ 0）なので，上腕長のばらつきは RS 側だけの指標
- 偏りはカメラ座標で定義している。皮膚表面と関節中心のずれが **体（前腕など）に固定**されていれば，腕の向きが変わるとカメラ座標での偏りは変わる（a3 の「位置による変化」に現れる）
