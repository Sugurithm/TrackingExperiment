## 1. 結論（5 行）

1. **「スコア」は 1 次元ではない**: 正確さ（on-target・RMS 誤差・遅れ）と、滑らかさ・安定性（躍度・速い揺れ・修正の頻度・外れる頻度）は、試行レベルでほぼ無相関（|r| ≤ 0.2）の別の次元。
2. **練度に近いのは滑らかさ・安定性**: 練度の順位との一致は、1.5 Hz 超の動きの割合（τ +0.78）、外れる頻度（+0.70）、fast の滞在時間（+0.78）が on-target（+0.62 / +0.45）より大きい。この傾向は **400 だけでも 800 だけでも同じ**だった（slow の 1.5 Hz 超・2–10 Hz の揺れは τ +0.70〜+0.78、両層で p ≤ 0.034。fast の滞在時間は両層で +0.78）。ただし同じ 8 人なので独立な再現ではない。q ≥ 0.06 で探索的。
3. **DPI 800 は正確さと滑らかさの交換**: fast では on-target +6.8 ポイント（9/9 人）、遅れ −17 ms（8/9 人）と正確になる。一方で両帯域とも、躍度は 1.4 倍（0/9 人が改善）、修正の頻度は +0.6 回/s（0/9 人）、速い揺れも増える。
4. **協調の型とエイムの質の関係は、人の間（9 人）では確認できない**。400 だけ・800 だけ・まとめた、のどの層でも p < 0.05 は 110 組中 0〜2 組で、偶然（5.5 組）以下。いちばん強い組も層ごとに入れ替わる。
5. **同じ人の試行間では、400 と 800 の両方で再現した組が 1 つだけある**: slow で、遠位（肘→MCP3）のシェアが大きい試行ほど実効遅れが大きい（生 r +0.49 / +0.50、両層 p < 0.05、手首の点を使わない指標）。初版で挙げたほかの候補は片方の DPI だけで出ていた。
   - 「遠位に偏った試行ほど不正確」「fast で前腕 ↔ 遅れが小さい」: 主に 800 で出る
   - 「手を使った試行ほどぎくしゃく」【参考】: 400 だけで強い
   
   まとめた値はこれらを平均して薄めていた。

## 2. エイムの質の指標

task.csv の 250 Hz のカーソル・ターゲットから、試行ごとに計算した。カーソルは DPI によらず 1 count あたり同じだけ動くので（実測 0.0317 mm / count）、カーソル空間の指標は 400 と 800 をそのまま比べられる。

| 側面 | 指標 | 定義 | 良い向き |
|---|---|---|---|
| 正確さ | on-target | ターゲット円内の時間の割合 [%] | ↑ |
| | RMS 誤差 | カーソル − ターゲットの 2D RMS [mm] | ↓ |
| 滑らかさ | 躍度比 | log10(RMS 躍度(カーソル) / RMS 躍度(ターゲット))。10 Hz 低域通過後。0 = ターゲットと同じ滑らかさ | ↓ |
| | 1.5 Hz 超の割合 | カーソル速度のパワーのうち、課題に無い帯域（> 1.5 Hz）の割合 | ↓ |
| | 修正の頻度 | 速さの山の数 [1/s] のターゲットに対する超過（断続的な修正動作） | ↓ |
| 安定性 | 2–10 Hz の揺れ | 2〜10 Hz のカーソル速度の RMS [mm/s]（ふらつき） | ↓ |
| | remnant | 入力周波数以外に出たカーソルのパワーの割合（a5、x・y 平均） | ↓ |
| | 外れる頻度 | ターゲットから外れる回数 [1/s]（20 ms 未満の出入りは除く） | ↓ |
| | 滞在時間 | ターゲット内に連続していた時間の平均 [s] | ↑ |
| | 誤差の変動係数 | 2 s 窓ごとの RMS 誤差の CV（試行内の出来のぶれ） | ↓ |
| 動特性 | 実効遅れ | 位相の傾きからの遅れ [ms]（a5、x・y 平均） | ↓ |

使わなかった指標が 2 つある。
- **SPARC**: 40 s の追従では、速さのスペクトルがターゲットへの追従ゲインに支配される。遅れて小さく追う試行ほど「滑らか」に出たため、使わなかった（値は CSV に残している）。
- **追従帯域（a5 の fb）**: 全条件で約 20 Hz に張り付いた。入力周波数（≤ 1.08 Hz）の範囲から外挿した値なので使わなかった。

### 2.1 指標どうしの関係

条件（人 × DPI × 帯域）と seed を除いた試行レベルの残差の相関。図: [`fig5_perf_corr.png`](perf_coordination/fig5_perf_corr.png)

- **正確さのまとまり**: on-target と RMS 誤差（r −0.63）、RMS 誤差と実効遅れ（+0.42）、RMS 誤差と remnant（+0.47）、RMS 誤差と誤差の変動係数（+0.43）。
- **滑らかさ・安定性のまとまり**: 躍度比と修正の頻度（+0.74）、躍度比と 1.5 Hz 超の割合（+0.68）、1.5 Hz 超の割合と 2–10 Hz の揺れ（+0.82）、2–10 Hz の揺れと外れる頻度（+0.44）。
- **2 つのまとまりの間**: |r| ≤ 0.2 がほとんど。例外は外れる頻度と on-target（−0.31）だけ。
- **結果**: on-target だけでは、滑らかさ・安定性の側面は見えない。

- **推測（DPI）**: 800 は eDPI が 2 倍（160 → 320）。手の同じ大きさのふるえ・修正がカーソルでは 2 倍になるので、速い揺れ・躍度が増えるのは**機械的に予想される**。一方で必要な手の移動量は半分なので、追従の遅れは短くなる。「戦略を変えた」と言う前に、この単純な説明を除く必要がある（例: 手の座標＝マウス変位で同じ指標を出し、手の側でも揺れが増えたかを見る）。**未確認**。
- **結果（個人差）**: ICC は躍度比 slow（0.12）以外で 0.5〜0.8。エイムの質の多くは個人特有。
- **結果（練度）**: 練度と並ぶのは、正確さ（on-target τ +0.62）よりも**速い揺れの少なさ・外れにくさ・滞在の長さ**（τ +0.70〜+0.78、p 0.011〜0.030）。ただし 8 人・q ≥ 0.11 で、補正に耐えた指標は無い。
- **推測（練度）**: 熟練者は「当てる」より「ブレずに留まる」点で違う可能性がある。練度の評価に on-target だけを使うのは不十分かもしれない。

## 3. 協調とエイムの質の関係

協調の指標 10 個を使った。手首に依存しないのは、手首なし N_eff・遠位シェア・体幹シェア・上腕シェア・近位/遠位の逆相。前腕シェア・S・C_corr は手首の点を含む。手シェアと 4 成分の N_eff は【参考】。これをエイムの質 11 個と、3 つの水準で組み合わせた。

### 3.1 B1 人物間（人の平均どうし、9 人）— 400+800 をまとめた層

（この節と §3.2 の数値は 400+800 をまとめた層。DPI の層ごとの結果は §3.4。図は 3 層すべてを並べてある）

図: [`fig1_between.png`](perf_coordination/fig1_between.png)、表: [`b1_between.csv`](perf_coordination/b1_between.csv)

- **結果**: 220 組のうち p < 0.05 は 1 組だけ（fast の C_corr と remnant、良い向き ρ +0.72、95 % CI −0.18〜+1.00、q = 1.0）。偶然に期待される数（約 11）より少ない。
- **結論**: 9 人では、「この協調の型の人ほどエイムが良い」とは言えない。

### 3.2 B2 条件内（同じ人・同じ DPI・同じ帯域の、試行間のばらつきどうし）— 400+800 をまとめた層

(人 × DPI) と seed（軌道と練習の順序）の効果を最小二乗で除いた残差の相関。1 帯域 54 試行で、自由度は 33（位相の指標は欠けがあり 27〜28）。図: [`fig2_within_condition.png`](perf_coordination/fig2_within_condition.png)、表: [`b2_within_condition.csv`](perf_coordination/b2_within_condition.csv)

| 帯域 | 協調 | 質 | 生 r [95 % CI] | 読み | p / q |
|---|---|---|---|---|---|
| slow | 遠位シェア | on-target | −0.40 [−0.64, −0.08] | 遠位に偏った試行ほど当たらない | 0.016 / 0.34 |
| slow | 遠位シェア | RMS 誤差 | +0.39 [+0.06, +0.64] | 同上 | 0.022 / 0.34 |
| slow | 遠位シェア | 実効遅れ | +0.47 [+0.16, +0.70] | 遠位に偏った試行ほど遅れる | 0.004 / 0.34 |
| slow | 手首なし N_eff | on-target / RMS 誤差 | +0.38 / −0.38 | 多くの関節で分担した試行ほど正確 | 0.025, 0.021 / 0.34 |
| slow | 手シェア【参考】 | 躍度比 / 修正の頻度 / 揺れ | +0.41 / +0.43 / +0.37 | 手を多く使った試行ほどぎくしゃく | 0.016, 0.011, 0.029 / 0.34〜0.35 |
| fast | 前腕シェア | 実効遅れ | −0.49 [−0.70, −0.18] | 前腕を多く使った試行ほど遅れが小さい | 0.003 / 0.30 |
| fast | 上腕シェア | 実効遅れ | +0.46 [+0.14, +0.68] | 上腕を多く使った試行ほど遅れる | 0.006 / 0.33 |

- **結果**: p < 0.05 は slow で 11 組、fast で 6 組（偶然に期待される数はそれぞれ約 5.5。slow はやや多い）。上の表は、互いに整合するまとまりを抜き出したもの。
  - slow: 遠位シェアと手首なし N_eff は、ほぼ同じ情報を反対の向きで持つ。どちらでも同じ向きの結果が出る。
  - fast: 前腕と上腕が遅れについて逆の向きに出る。
- **補正後**: どれも q ≥ 0.30。「関係がある」とは言えない段階。
- **推測（因果の向きに注意）**:
  1. 協調 → 成績: 肩・上腕も参加させた試行のほうが正確に追える（slow）。前腕主体のほうが素早く追える（fast）。
  2. 成績 → 協調: 大きく外れた試行では、手首・前腕で素早く大きく修正するので、遠位のシェアが上がる。この向きでも同じ相関が出る。
  3. 第 3 の要因: 集中・疲れ・姿勢のずれが両方を動かす。
  
  B2 はどれも区別できない。区別には、試行内の時間の前後関係（協調の変化が誤差の変化に先行するか）を見る解析が要る（§5）。
- 手シェア（参考）とカーソルの揺れの関係について。手の成分は入力周波数（≤ 1.08 Hz）のビンだけで作り、揺れは 2〜10 Hz のカーソル（マウス）で測っている。同じ信号を 2 回数えたわけではない。ただし手首・MCP3 は MoCap 未照合なので【参考】。

### 3.3 B3 DPI による変化どうし（Δ800−400、9 人）

| slow | ΔS | Δ2–10 Hz の揺れ | −0.84 [−1.00, −0.46] | 800 で S を保った（下げなかった）人ほど、揺れの増え方が小さい | 0.007 / 0.67 |
| slow | ΔS | Δ1.5 Hz 超の割合 | −0.81 [−0.98, −0.26] | 同上 | 0.012 / 0.67 |

- **B2 との食い違い**: B2 では「手を多く使った試行ほどぎくしゃく」、B3 では「800 で手を多く使うようになった人ほど揺れの増え方が小さい」と、向きが逆に見える。
- **推測**: 状態（試行ごとのゆらぎ）と適応（DPI に合わせた組み替え）の違いかもしれない。後者は「高 DPI で手首側に分担を移すと、2 倍になる揺れの影響を抑えられる」という仮説になる。どちらも補正に耐えておらず、**未確認**。

### 3.4 DPI の層ごとの結果（400 だけ / 800 だけ / 400+800）

図: [`fig1_between.png`](perf_coordination/fig1_between.png)、[`fig2_within_condition.png`](perf_coordination/fig2_within_condition.png)（上から 400 だけ・800 だけ・400+800）
表: [`b1_between.csv`](perf_coordination/b1_between.csv)・[`b2_within_condition.csv`](perf_coordination/b2_within_condition.csv)（`stratum` 列）、[`dpi_heterogeneity.csv`](perf_coordination/dpi_heterogeneity.csv)、[`skill_by_dpi.csv`](perf_coordination/skill_by_dpi.csv)

**なぜ分けたか**: 初版の B1 は各人の値を 400 と 800 で平均していた。B2 は (人 × DPI) の平均を引いたうえで 400 と 800 の試行を 1 つの相関にまとめていた。DPI の差そのものは除いていたが、「協調と質の関係は 400 でも 800 でも同じ」と仮定していたことになる。800 では手の動きが半分になり、揺れはカーソルで 2 倍になるので、関係が DPI で変わることは十分ありうる。

**層ごとの要約**（p < 0.05 の組の数。偶然に期待される数は 110 組中 5.5）

| 水準 | 帯域 | 400 だけ | 800 だけ | 400+800 | 最小の q（400 / 800 / まとめ） |
|---|---|---|---|---|---|
| B1 人物間（9 人） | slow | 1 | 1 | 0 | 0.99 / 0.97 / 0.98 |
| | fast | 1 | 1 | 2 | 1.0 / 1.0 / 1.0 |
| B2 条件内（各層 27 試行、まとめは 54） | slow | 7 | 8 | 11 | **0.052** / 0.64 / 0.34 |
| | fast | 6 | 5 | 6 | 0.75 / 0.52 / 0.30 |

**400 と 800 の両方で再現したか**（同じ向き、かつ両層で p < 0.05）:

| 水準 | 帯域 | 協調 | 質 | 400 | 800 | まとめ |
|---|---|---|---|---|---|---|
| B2 | slow | 遠位シェア（手首なし） | 実効遅れ | 生 r +0.49（p 0.048） | 生 r +0.50（p 0.043） | +0.47（p 0.004） |

220 組中この 1 組だけ。B1 では 0 組。2 つの層が独立なら偶然の期待は約 0.3 組だが、同じ 9 人なので完全な独立ではない。
- **読み（結果）**: 同じ人・同じ DPI のなかで、肘から先に偏って動いた試行ほど、ターゲットへの追従が遅れていた。DPI によらない。
- **読み（推測）**: 向きはどちらもありうる。
  - 遠位で動かすと遅れる。
  - 遅れて誤差が大きくなった試行で、手首・前腕で急いで取り返そうとして遠位が増える。

**400 と 800 で関係が違うか（異質性の検定）**:
- B2: r(800) − r(400) の Fisher z。同じ人を含むので近似。
- B1: 人を対にしたブートストラップ。
- 結果: 差の p < 0.05 は B2 で 9 / 220 組、B1 で 2 / 220 組。偶然に期待される 11 組より少なく、最小 q は 0.42 / 1.0。
- **全体としては「関係が DPI で変わる」証拠も無い**。27 試行ずつ（自由度 15）では、差を検出する力がそもそも小さい。
- **推測**: 手シェア ↔ 揺れ（400 だけ）が本物なら、次の解釈になる。400 では手首の動きが「速い修正」として揺れに直結する。800 では揺れの大部分がカーソルへの拡大（eDPI 2 倍）から来るので、手首の寄与が埋もれる。**未確認**。手首・MCP3 が MoCap 未照合である点も変わらない。

**練度（τ）の層ごとの値**: 400 だけ・800 だけでも、練度と並ぶ指標はほぼ同じ。
- slow の 1.5 Hz 超: 400 で +0.70、800 で +0.78
- slow の 2–10 Hz の揺れ: 400 で +0.70、800 で +0.78
- slow の外れる頻度: 400 で +0.70、800 で +0.62
- fast の滞在時間: 400 で +0.78、800 で +0.78

最小の q は 0.06（800 の slow の 1.5 Hz 超・揺れ）。on-target は 400 で +0.62、800 で +0.54 と、どちらの層でも滑らかさ・安定性より弱い。

**まとめた層を報告するときの注意**: 400+800 の B2 は試行数が 2 倍で検出力が高い。ただし片方の層だけの関係も「平均」として拾うし、逆向きの関係は打ち消す。今後は **3 層を並べて、両層で同じ向きのものを主な結果にする**のがよい。

## 4. 限界

- **人数と検定の数**: 9 人（練度は 8 人）に対して、指標の組は 110 × 2 帯域 × 3 水準。補正に耐えた関係は無い。**ここで挙げた組は「次に事前登録して確かめる候補」**であって、結果として主張しない。
- **練度の情報が粗い**: 3 群の順位だけ。熟練者ほど DPI 800（高 eDPI）に慣れている、などの交絡の可能性があるが、普段のセンシ・DPI は記録していない。
- **滑らかさの指標は前処理に依存する**: 10 Hz の低域通過、速さの山の prominence = 0.1 SD、1.5 Hz の境界。境界を変えた感度分析は未実施（**未確認**）。
- **DPI の効果と記録順の効果を完全には分けられない**（400 先 3 人 : 800 先 6 人）。
- **手首・MCP3 の点を含む指標**（手シェア、前腕シェア、S、C_corr、4 成分の N_eff）は MoCap 未照合。手首なしの指標（遠位シェア、手首なし N_eff、上腕・体幹シェア）を優先して読むこと。

## 5. 次に取るべき解析・データ

1. **試行内の時間の前後関係**: 5〜10 s の窓ごと、またはターゲットの反転ごとに、関節の寄与と誤差・揺れを並べる。協調の変化が誤差に先行するか（Granger 型、交差相関のラグ）を見て、B2 の因果の向きを絞る。
2. **手の座標での滑らかさ**: マウス変位（mm）で躍度・揺れを出し直す。800 の揺れの増加が「カーソルへの拡大」だけで説明できるか（手の揺れは変わらないか）を確かめる。
3. **事前に指標を絞った確認実験**: 今回の候補を事前に決めて検定する。
   - slow: 遠位シェア ↔ 正確さ・遅れ
   - fast: 前腕 / 上腕シェア ↔ 遅れ
   - 練度 ↔ 速い揺れ・滞在
   
   15〜20 人、DPI は 3 水準で順序をランダムに。
4. **練度の客観化**: ゲーム内ランク、プレイ時間、普段の eDPI。練度と DPI の慣れの交絡を分ける。
5. **混合効果モデル**: エイムの質 ~ 協調（人内で中心化した成分 + 人の平均）+ DPI + 帯域 + seed + (1 | 人)。B1 と B2 を 1 つのモデルで推定する。
