# 予備解析の報告（2026-10-22）: FPS エイム時の上肢の関節協調

- 対象: 9 人（kakeru, Keito, Kosuke, Suguru, Suzuka, Syou, xin, Yuuki, Yuya）× DPI 400 / 800 × 帯域 slow / fast × seed 3 本 = **本番 108 試行**（静止 18 試行はノイズ床の測定にだけ使う）
- 主解析 = `prelim_relaxed/`（除外 0 本）。感度解析 = `prelim_strict/`（config.GATE をそのまま適用、15 本除外、93 本）。**下の結論は両方で向きが同じ**（数値は主解析）
- 「d」= 人ごとの (800 の seed 平均) − (400 の seed 平均)。dz = mean(d)/SD(d)。CI は人を単位にしたブートストラップ 95 %。「k/9 人」= 同じ向きの人数。「再現」= slow と fast で d の符号が一致した人数
- 実行の手順と設定は [`run_log.md`](run_log.md)

## 1. 結論（5 行）

1. **関節依存性**: 手先の動きの大半は「肘から先の振り（前腕成分 49〜63 %、肘→MCP3 の遠位成分 76〜84 %）」が担い、前腕成分が主役なのは 9 人全員・4 条件中 35/36。ただし一関節依存ではなく N_eff = 2.1〜2.6 / 4（2 関節ぶん程度の分担）。
2. **協調様式**: 関節が一つずつ動くのではなく**同時に動き、方向で分担する**。左右（x）は前腕 + 手、前後（y）は上腕 + 前腕 + 体幹。S ≈ 0.72（< 1）はこの方向の分担で説明でき、速さ（周波数）による分担はほとんど無い。時間の包絡の相関 R は正（+0.15〜+0.38）。近位→遠位の順序ではなく、むしろ遠位がやや先行（位相 +37〜+69°）。打ち消し合いは小さい（C_corr 1.03〜1.17）。
3. **DPI 効果（人物内）**: 800 では上腕・前腕・体幹の振幅がほぼ必要量どおり半分に縮み（log2 比 −1.0〜−1.2、9/9 人、両帯域で再現）、**手首の点を使わない分担構造は変わらない**（3 成分 N_eff の d = −0.03、dz −0.29）。手の成分だけは半分まで縮まず（×0.68）、手のシェアが +0.10 上がる（9/9 人）が、手首・MCP3 は MoCap で照合できていないので**参考値**。
4. **個人差（人物間）**: 分担の構造は個人特有。手首なしの N_eff は ICC 0.78（D 1.92）、遠位シェアは ICC 0.81（D 2.10）。人の順位は DPI をまたいで ρ = +0.75、帯域をまたいで ρ = +0.98 で保たれる。**練度との関連は検出されなかった**（8 人、|τ| ≤ 0.48、p ≥ 0.18）。

### 2.2 協調様式（逐次か同時か）

図: [`prelim_relaxed/fig5_direction.png`](prelim_relaxed/fig5_direction.png)（方向ごとの分担）、[`prelim_relaxed/fig3_robustness.png`](prelim_relaxed/fig3_robustness.png)（C と C_corr、S と R）

| 条件 | x（左右）: 前腕 / 手 / 上腕 | y（前後）: 上腕 / 前腕 / 体幹 / 手 | 低周波半分 / 高周波半分の前腕シェア | S | R（信頼できる試行のみ） | C（a1）→ C_corr | 遠位−近位の位相 |
|---|---|---|---|---|---|---|---|
| slow 400 | 83 / 16 / 0 % | 61 / 23 / 16 / 0 % | 63 / 64 % | 0.74 | +0.38（8 人） | 1.11 → 1.03 | +37°（9/9 人が正） |
| slow 800 | 67 / 30 / 2 % | 58 / 26 / 15 / 1 % | 51 / 54 % | 0.72 | –（信頼できる試行なし） | 1.20 → 1.10 | +69° |
| fast 400 | 79 / 20 / 1 % | 66 / 28 / 6 / 0 % | 59 / 60 % | 0.72 | +0.18（9 人） | 1.20 → 1.11 | +60° |
| fast 800 | 59 / 39 / 2 % | 57 / 34 / 7 / 2 % | 49 / 49 % | 0.73 | +0.15（4 人） | 1.28 → 1.17 | +39° |

読み方:
- **結果**: S が 1 より小さい（0.72〜0.74。合成データでは「同時」1.00、「交代」0.58）。ただし周波数を低い半分と高い半分に分けてもシェアはほぼ同じで（上の表）、方向（x / y）で分けると分担がはっきり違う。S はビンを x 軸・y 軸まとめて扱うので、**方向による分担でも 1 より小さくなる**。今回の S < 1 は「関節が一つずつ交代で動く」ことを示すものではない。
- **結果**: 時間領域の R は正。成分の活動量が一緒に増減している。「交代（R < 0）」の証拠は無い。
- **結果**: 近位（肘の位置）と遠位（肘→MCP3）の位相差は、遠位が先行する向き（slow 400 で 9/9 人が正、最小 +17°）。近位→遠位の順に動く逐次型ではない。ただし両成分とも SNR > 2 のビンは 1 試行 3〜7 個と少なく、ICC も低い（0.11〜0.56）。**参考程度**。
- **結果**: a1 の C（1.11〜1.28）は、ノイズパワーを引いた C_corr では 1.03〜1.17 に下がる。隣り合う成分は関節を共有するので、関節のジッタが逆符号で両方に乗り、C を押し上げる。**打ち消し合いながら手先を作る協調はあっても小さい**。
- **推測**: 「左右は前腕を振り（手首で微調整）、前後は上腕で押し引きする、方向分担の同時協調」。

## 4. 限界と、次に取るべきデータ

**計測の妥当性**
- **手首・MCP3 は MoCap で照合できていない**。今回 `mocap_joints.py → compare_joints.py` を RHandOut を手の点として再実行した（`mocap_check/`、2 本で比較）。結果、手首の角度は使えない水準だった:
  - 手首・屈曲: r = 0.54 / 0.14、振幅比 0.95 / 1.15、偏りを除いた RMS 7.3° / 10.1°
  - 手首・偏位: r = 0.09 / −0.50、振幅比 1.56 / 2.11
  - 参考までに、肘・屈曲は r = 0.81 / 0.92、振幅比 0.94 / 0.73
  
  このため a8 の手首の自由度と、a1 の「手」成分（MCP3 − 手首）は参考値として扱った。10/16 の 2 本は較正ファイル（`calib_20261016_1850/T_MC.json`）が無く、比較できなかった。
- **手先 / マウスのゲインが 1 でない**（中央値 0.80、800 と fast で小さい）。MCP3 とマウスのセンサの位置の違い（手の回転で動く量が違う）か、RealSense が小さい動きの振幅を過小に捉えているか、どちらかは**未確認**。後者なら 800 の振幅の比較（log2 比）がやや縮み側に偏る。
- 関節推定の設定: `experiment/config.py` は現在 `POSE_VARIANT = "full"`。README で精度を確かめたのは heavy。今回の npz がどちらで推定されたかは試行ごとに記録されておらず、**未確認**。
- MoCap の比較試行（大きな腕の動き）では、肘・手首の位置の「偏りを除いた RMS」が 85〜115 mm あった。エイム課題の動き（手先の変位 RMS 30〜100 mm）は周波数ビンのノイズを引いて扱っているが、動きと相関する系統的な誤差は引けない。

**デザイン**
- 9 人・2 DPI・各 3 seed。DPI の順序は 3 人 : 6 人で部分的にしか釣り合っていない。
- 練度は与えられた 3 群の順位だけ（8 人）。普段のゲーム内センシ・DPI、利き手、マウスの握り方（かぶせ / つかみ / つまみ）を記録していない。

**次に取るべきデータ**
1. **MoCap 照合**: 手に 2〜3 マーカー（手背・MCP3・MCP5 付近）を付け、エイム課題そのもの（同じ振幅・同じ姿勢）で RealSense と同時に記録する。手首成分・肩の回旋の妥当性を確かめるのが最優先。
2. **DPI の追加と順序の釣り合い**: 400 / 800 / 1600 を被験者ごとにランダムな順序で（1600 は 3 人ぶん記録済み、関節の推定が未実施）。各条件の seed を 3 → 5 に増やすと、人物内の z が安定する。
3. **被験者数**: ICC の CI 幅（現状 ±0.3 程度）を半分にするには 20 人前後。練度の効果を見るなら 1 群 8〜10 人以上と、練度の客観指標（ゲームのランク・プレイ時間・課題成績）。
4. **記録の付帯情報**: 普段のセンシ（cm/360）・DPI、握り方、机と椅子の高さ、マウスの重さ。
5. Syou の確認動画（`trial_*/joints/joints_check_20fps.mp4`）を目視して、肩の動きが本物かを確かめる。

## 5. 修士で追加検討すべき解析

- **セグメント座標系（ISB 推奨）**: 胸郭・上腕・前腕・手に座標系を置き、肩の屈曲 / 外転 / 回旋、肘の屈伸、前腕の回内外、手首の掌背屈 / 撓尺屈を関節角として出す。今回の「前腕成分」が肩の回旋なのか肘なのかを分けられる。
- **前腕の回内外**: RealSense の 3 点では原理的に求まらない。MediaPipe Hand の MCP2・MCP5 を加えて手の平面を作るか、MoCap の前腕・手のボーンの相対回転を使う（MoCap 側では SD 8.6〜10.3°、可動域 27〜29° 動いていた）。
- **UCM（非制御多様体）解析**: 試行間・周期間の関節角のばらつきを、手先を変える成分と変えない成分に分ける。今回の C_corr（打ち消し合い）よりも直接に「冗長性を使った協調」を測れる。
- **方向別の指標**: S を x / y 別に計算し直し、方向の分担と速さの分担を分けて定量化する（今回わかった S の解釈の問題への対処）。
- **時間変化と学習**: 試行内の前半 / 後半、試行間の順序で分担がどう変わるか。DPI を変えた直後の適応の過程。
- **混合効果モデル**: 人をランダム効果、DPI・帯域・seed・順序を固定効果にして、効果量と個人差を 1 つのモデルで推定する（試行の入れ子構造を正しく扱う）。
- **筋電（EMG）**: 三角筋・上腕二頭筋 / 三頭筋・前腕屈筋群 / 伸筋群。運動学で同じに見える分担が、筋の使い方（共収縮など）で違うかを見る。
- **成績との因果**: 介入（DPI・センシを固定して数日練習させる、肘の支持の有無など）で分担を変え、成績が変わるかを見る。相関だけでは向きが決まらない。
